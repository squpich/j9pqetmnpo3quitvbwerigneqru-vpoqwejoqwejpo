# Production launch checklist

Before publishing:

1. Replace `https://example.com/` in:
   - `index.html`
   - `robots.txt`
   - `sitemap.xml`

2. Replace placeholders in `js/config.js`:
   - phone
   - email
   - WhatsApp
   - form endpoint

3. Set the form mode to `endpoint`.

4. Replace:
   - founder image placeholder;
   - demo report numbers, if required;
   - SVG social preview with a final PNG/JPG image for broader social compatibility.

5. Add:
   - privacy policy page;
   - terms page;
   - legal company details.

6. Test:
   - form submission;
   - mobile Safari;
   - Android Chrome;
   - desktop Chrome, Safari, Firefox and Edge;
   - language switching;
   - all phone and WhatsApp links.

7. Run:
   - Lighthouse;
   - HTML validator;
   - accessibility audit;
   - broken-link check.

8. Update the sitemap date before launch.
